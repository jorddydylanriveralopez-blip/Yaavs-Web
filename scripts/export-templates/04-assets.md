# 04 — Assets

Todo vive bajo `sitio/assets/`.

## Carpetas (orden lógico)

| Carpeta | Uso |
|---------|-----|
| `assets/` (raíz) | Logos, heroes sueltos, favicon PNG |
| `assets/hero-telecom/` | Hero home / telecom (foto + video) |
| `assets/hero/` | Variantes de hero |
| `assets/quienes/` | Quiénes somos (ciudad, filosofía, etc.) |
| `assets/historia/` | Timeline / historia |
| `assets/servicios/` | Fotos e iconos de servicios + videos |
| `assets/tiendas/` | Tiendas / atmósfera |
| `assets/operadores/` | Portadas operadores (ATT, BAIT…) |
| `assets/rotulaciones/` | Galería rotulaciones |
| `assets/testimonios/` | Fotos testimonios |
| `assets/yaavser/` | Material ser Yaavser |
| `assets/bolsa/` | Bolsa de trabajo |
| `assets/avisos/` | Materiales de anuncios / PDFs |
| `assets/planes/` | Planes / ofertas |
| `assets/esim/` | eSIM |
| `assets/floats/` | Decoración flotante |
| `assets/illustrations/` | Ilustraciones |
| `assets/intro/` | Intro |
| `assets/pwa/` | Iconos PWA |
| `assets/social/` | Redes |
| `assets/valores/` | Valores |
| `assets/vinculaciones/` | Vinculaciones |
| `assets/yaavshop/` / `yaavstys/` | Productos / Yaavstys |

## Notas

- `assets/avisos/` puede estar casi vacío: el chip PDF de Anuncios apunta a `recargaklic-jun2026.pdf` (hay que subir el archivo cuando exista).  
- Videos grandes van en `assets/servicios/videos/` y `assets/hero-telecom/`.  
- Preferir nombres en kebab-case y versionar con `?v=` en el HTML.
